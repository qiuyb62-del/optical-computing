# 第三阶段 SVD 矩阵乘法

状态：已完成（2026-11-02 验证）

本阶段实现一般实数/复数方阵 W 的矩阵向量乘法。SVD 得到 W=UΣV†，用两套现有 Clements 网格实现酉变换，中间加入被动幅度衰减。令 s=max(1,sigma_max)，实际光路为 V† → diag(sigma/s) → U，输出 Wx/s，最后数字乘 s 恢复 Wx。

## 已交付

- `src/svd_matmul.py`：配置生成、逐器件传播、中间光场、原始输出与数字恢复、矩阵重建。
- `src/svd_validation.py`：统一误差和功率验收。
- `demo_week03.py`：4×4 复数示例，可切换尺寸与实数模式。
- `verify_week03.py`：批量验证和可复现 JSON 报告。
- `tests/test_svd_matmul.py`：新增 35 项测试；连同原有 61 项，共 96 项通过。
- `docs/svd-matmul.md`：完整接口与判据；统一标准已同步更新。
- `results.json`：批量结果；`example_4x4.json`：目标矩阵、输入、器件参数、中间光场与最终答案。

## 复现

```sh
python demo_week03.py --size 4 --seed 42 --report progress/03_svd_matmul/example_4x4.json
python verify_week03.py
python -m pytest -q
```

环境沿用 Python 3.12.4、NumPy 2.4.1、pytest 8.3.5；没有新增依赖。批量种子为 20261102，每个尺寸 100 个随机矩阵，实数与复数交替，整体系数 0.01、1、100 轮换。

每个尺寸另加 7 个特殊矩阵：零矩阵、单位矩阵、有正负元素的对角衰减矩阵、复数对角增益矩阵、秩一矩阵、不满秩对角矩阵、条件数 10¹² 的对角矩阵。每个矩阵验证 N 个基向量、一个随机复向量及一个零向量，并复用同一份光路配置。

共 321 个矩阵、2,140 组输入通过。表中输出相对误差仅统计使用相对判据的样本；理论为零或接近零时，单独按有尺度的绝对误差验收，计数及最大绝对误差见 results.json。所有原始光学输出、网格功率守恒及被动性检查也通过。完整判据见 `docs/svd-matmul.md`。

默认 4×4 示例中，s≈3.60576740；矩阵相对误差约 8.43×10⁻¹⁶，恢复输出相对误差约 8.29×10⁻¹⁶。输入功率约 3.65149，实际光路输出功率约 2.90644。数字恢复后的模平方不作为光学输出功率。
