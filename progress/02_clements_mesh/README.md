# 第二阶段 Clements 网格

状态：已完成（本周代码，2026-10-26 验证）

本阶段实现 `U → MZI 参数与输出相位 → 逐器件传播 x → y≈U@x`。没有改变第一阶段的 MZI 矩阵约定。

## 已交付

- `src/clements.py`：Clements 自动分解，完整保留复相位，处理零元素与奇偶通道数。
- `src/mesh.py`：网格传播、重建与分层显示。
- `demo_week02.py`：可直接运行的 4 通道示例，也可切换尺寸。
- `verify_week02.py`：固定随机种子批量验证。
- `docs/clements-decomposition.md`：接口、数学关系和验收说明。
- `results.json`：批量实验结果；`example_4x4.json`：完整示例参数、输入和输出。复数按 real/imag 两部分保存，参数单位为 rad，通道从 0 编号。

## 复现命令

在项目根目录运行：

```sh
python demo_week02.py --size 4 --seed 42 --report progress/02_clements_mesh/example_4x4.json
python verify_week02.py
python -m pytest -q
```

本机环境：Python 3.12.4、NumPy 2.4.1、pytest 8.3.5。批量实验随机种子 20261026；每个尺寸 100 个随机复酉矩阵，加单位、反序置换、对角相位、Fourier 四种特殊矩阵。全部比较完整复数矩阵与光场，不对齐全局相位。

| 通道数 | MZI 数量 | 验证矩阵数 | 最大矩阵重建相对误差 |
|---|---|---|---|
| 2 | 1 | 104 | 8.82×10⁻¹⁶ |
| 4 | 6 | 104 | 9.46×10⁻¹⁶ |
| 8 | 28 | 104 | 1.46×10⁻¹⁵ |

全部低于 1×10⁻¹⁰ 验收阈值。光场输出、总功率与重建酉性检查也全部通过，具体数值见 results.json。不同平台的末位浮点误差可能不同。
