# 第六阶段：MNIST 手写数字验证协议

Iris 是第五阶段，完整保留。MNIST 是后续更复杂的十分类研究；沿用相同的复光场、MZI、Clements、SVD 和静态器件误差标准。下列默认协议在正式训练和测试前固定，不根据测试准确率调参。

## 数据与划分

- 官方 MNIST：60,000 张训练图片、10,000 张官方测试图片，28×28 灰度，标签 0–9。不使用 sklearn 的 8×8 digits 替代。
- 训练集按 seed=20261109 分层打乱，每类抽 1,000 张作为验证集；剩余 50,000 张训练。官方测试集全部保留，索引顺序不变。
- 图像先除以 255。仅用 50,000 张训练图片拟合均值与 PCA，保留 16 个主成分，不白化、不另行标准化。PCA 特征可能为负，仍编码为带相位的复场幅度。
- 三个模型使用同一划分和 PCA；训练种子为 20261109、20261110、20261111。保存划分、PCA、权重、历史和数据校验值。
- 数据下载文件校验值来源于 torchvision v0.24.1 的 MNIST loader；文件需显式下载，离线演示不联网。

## 模型与光学边界

28×28 图片 → 数字 PCA 16 维 → **光学 16×16 权重乘法** → 数字偏置与 ReLU → 数字 16→10 分类头 → 类别。

CPU float64；Adam，学习率 0.001，batch=256，最多 50 epochs；验证损失连续 8 次未改善即停止，改善阈值 10⁻⁶。包含初始 epoch 0 候选，仅按验证损失选择模型。测试集只用于最终评估。无校准、无带噪重训练。

第一层 W1 按 W[out,in] 保存，分别编译一次。每套 Clements 网格有 120 个 MZI，两套共 240 个；中间 16 个幅度衰减器。被动光学输出为 W1x/s，s=max(1,σmax)；数字恢复 s 后在共同相位参考下读取 Re(E)。此处假设能获得相干复场，尚未模拟实际相干接收器。

批量传播仅把多张图片的独立输入并行处理，仍按顺序经过每一个 2×2 MZI；禁止用稠密 W1 矩阵乘法代替光路传播。偏置、非线性、PCA 和末层在电子端运行；不声称全光神经网络、真实硬件速度优势或 Lumerical 结果。

## 配对评估

每个冻结模型在相同的 10,000 张官方测试图片上比较数字推理、理想光路、零误差物理器件模型以及以下条件：

| 条件 | 固定设置 |
|---|---|
| phase_0.01 | 静态相位偏差标准差 0.01 rad |
| phase_0.1 | 静态相位偏差标准差 0.1 rad |
| bits_6 | 6 bit 相位量化 |
| combined | 0.01 rad、每 MZI 0.1 dB 功率损耗、8 bit、耦合器 through=0.49 |

每个条件/模型 10 个器件种子：SeedSequence([model_seed, 0xA2, trial]) 产生 uint64，同一 trial 在条件间配对。每个器件采样一次后处理全部测试图像，不逐图重新采样。纯量化条件是确定性重复，不是十个独立制造样本。

共 3 个模型、120 个非理想配置、1,200,000 次非理想预测；重复使用的测试图片仍只有 10,000 张。报告每个模型和各器件准确率、相对数字基线变化（百分点）、交叉熵、混淆矩阵、复场/分类输出误差、预测一致率与被动性。均值/标准差描述该固定实验，不是总体置信区间。

验收：导出权重与 PyTorch 输出误差 <10⁻¹⁰；矩阵重建相对误差 <10⁻¹⁰；理想/零误差复场与数字输出 allclose(atol=rtol=10⁻¹⁰)，预测完全一致；批量传播与逐样本传播相符；各被动阶段功率不增加。非理想准确率不设通过门槛，下降幅度是研究结果。
