# 第四阶段 器件误差模型

本阶段完成 Python 传输矩阵模型中的静态相位误差、额外损耗、有限位数相位控制和耦合器偏差。保持原来的 MZI convention、Clements 分解、SVD 缩放和复数输入输出不变。Lumerical、空间电磁场和 AI 验证留待后续阶段。

## 1 光路多做了什么

原来的流程：`W → SVD → 两套 Clements 网格 → 理想输出`。

现在的流程：`理想配置 → 设置控制分辨率 → 抽取一次器件偏差 → 固定非理想光路 → 输入多个 x → 与 NumPy Wx 比较`。

同一个器件的偏差在不同输入之间保持不变；不能每算一个基向量就重新随机，否则这些基向量将不再描述同一个线性系统。`realize_nonideal` 只在创建器件时使用随机数，`propagate_nonideal` 不采样、不重新分解、不调用目标矩阵 `W @ x`。

## 2 物理控制相位与原数学标准

原标准仍然是：

```text
T(θ,φ) = [[exp(iφ)cosθ, −sinθ],
          [exp(iφ)sinθ,  cosθ]]
```

定义耦合器直通**功率比** η：

```text
B(η) = [[sqrt(η),       i sqrt(1−η)],
        [i sqrt(1−η),   sqrt(η)    ]]

M = diag(exp(iχ_upper), exp(iχ_lower))
    @ B(η)†
    @ diag(exp(iδ), 1)
    @ B(η)
    @ diag(exp(iφ), 1)
```

理想映射为 `η=0.5, δ=2θ, χ_upper=χ_lower=−θ`，可以直接推得 `M=T(θ,φ)`，包括完整复相位。两端补偿相位如果省略，会多出 `exp(iθ)`，因此不能为了匹配结果再逐向量对齐相位。输出耦合器明确采用 `B†` 的端口相位约定；未来在 Lumerical 中必须核对，不能直接把任意内置耦合器的参数代入。

这是一种有明确控制量的等效实现，并不声称是最少相移器的硬件布局。每个 MZI 保存 `(φ,δ,χ_upper,χ_lower)` 四个控制相位，两个网格各自的 N 个输出相位也保留。N=4 时共 12 个 MZI、8 个网格输出相位；相位偏差作用于 12×4+8=56 个控制量。θ 仍然是原分解的有效混合角，未改为物理臂相位。

## 3 误差定义与顺序

`NonidealConfig` 的字段如下。默认全部理想。

| 参数 | 含义 | 默认 |
|---|---|---|
| `phase_std_rad` | 每个相位控制量独立的静态零均值高斯偏差标准差，rad | 0 |
| `loss_db_per_mzi` | 每个 MZI 对两个输出相同的额外插入功率损耗，dB | 0 |
| `phase_bits` | 每个相位控制量的位数，1–32；None 表示不量化 | None |
| `coupler_through` | 两个耦合器相同的直通功率比 η，范围 [0,1] | 0.5 |
| `upper_arm_loss_db` | 每个 MZI 内部上臂额外功率损耗，dB | 0 |

**相位控制：** 先对物理相位命令量化，再加静态偏差。步长 `Δ=2π/2^b`，相位周期为 2π，取最近格点；恰好位于中点时采用 round-to-even。即 `phase_actual = Q(phase_command) + Normal(0,σ)`。原标准中的有效 θ 不直接量化。这一版研究物理控制相位的 σ，而不是把 σθ 与 σφ 混称为同一参数。

**损耗：** L dB 表示功率乘 `10^(−L/10)`，场幅度乘 `10^(−L/20)`。额外上臂损耗放在两个耦合器之间；均匀插入损耗乘整个局部 2×2 矩阵。在 N>2 网格中，不同路径可能经过不同数量的器件，因此“每个 MZI 相同损耗”不等同于“整条光路统一乘一个系数”。对 N=2 的两套网格，每个输入恰好经过两个 MZI，额外统一损耗的解析结果为 `W_loss = 10^(−2L/20) W`，已作为独立测试。

**耦合器：** η 是确定性的系统偏差，两个耦合器都使用同一 η；目前不是随机制造分布。B(η) 始终酉。相位噪声、量化和耦合比改变不会凭空引入增益；有损单元是收缩变换。SVD 中间的目标衰减器仍理想。

目前不包含动态相位噪声、热串扰、波长色散、光电探测噪声、衰减器误差和控制电压标定。上述 σ、损耗和耦合比是敏感度扫描设定，不是测得的器件规格。

## 4 最小使用方法

```python
import numpy as np
from src.svd_matmul import compile_svd
from src.nonideal import NonidealConfig, realize_nonideal, propagate_nonideal

W = np.array([[1, 2j], [3, 4]], dtype=complex)
x = np.array([1, -1j])
ideal = compile_svd(W)
config = NonidealConfig(phase_std_rad=0.01, loss_db_per_mzi=0.1, phase_bits=8)
device = realize_nonideal(ideal, config, seed=20261109)
y = propagate_nonideal(x, device)
print(y, W @ x)
```

- `trace_nonideal` 返回与第三阶段相同的四个观察点，便于查看功率和完整复数光场。
- 默认输出已经数字乘 s；`restore_scale=False` 返回原始光学输出。
- `reconstruct_nonideal` 通过固定器件的基向量响应重建矩阵，只供验证。
- `device.to_dict()` 保存控制命令、实际相位、局部矩阵、参数、seed 和恢复比例，可审计本次器件。示例另存 W、x 以及原理想配置。
- 输入不修改；配置及局部矩阵使用不可变 tuple；不改变 NumPy 全局随机状态。

## 5 批量实验与判据

`python verify_week04.py` 在 N=2、4、8 上各生成 20 个独立目标矩阵，实数/复数交替，整体尺度 0.1、1、10 循环。每个目标编译一次，每个条件生成 30 台器件，每台输入 N 个基向量和 2 个随机复向量。所有条件共享目标、输入和器件 seed；标准正态随机数的抽取顺序保持一致，便于配对比较。

共 16 个条件：理想、4 个相位偏差、3 个插入损耗、3 个量化位数、3 个耦合比、1 个上臂损耗和1个组合设置。输出汇总涵盖 28,800 个条件内器件配置和 192,000 组输入。理想条件中不同 seed 的零噪声器件等价，不应把重复基线当作独立硬件测量。另用 21 个结构化矩阵检查零矩阵、不满秩、增益、病态情况和零/近零输出。

误差与第三阶段相同：完整复数矩阵 Frobenius 相对误差、完整复数输出相对误差；无全局相位对齐。零或近零结果按第三阶段绝对判据处理。随机扫描数据没有主动生成零分母；结构化理想回归单独覆盖这些边界。

误差汇总是中位数、经验 5%–95% 分位范围和最大值，分位范围不是置信区间。`fraction_exceeding_ideal_vector_tolerance` 表示超过理想数值阈值 1e−10 的比例，**不表示软件失败率，也不是 AI 分类错误率**。扫描中的误差由指定器件偏差导致，预期会高于理想舍入误差。

总体 PASS 检查两件事：零误差配置恢复理想结果；所有条件的原始光路满足被动性。不会要求有明显器件误差的输出仍等于 Wx。数字恢复后结果的模平方不能当作光功率。
