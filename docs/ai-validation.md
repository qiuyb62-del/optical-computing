# 第五阶段 AI 验证方案

目标：证明训练好的分类器第一层可以由现有光路执行，并量化指定器件误差对分类的影响。此次不加入校准、不进行噪声训练、不声称提出新算法。以下默认方案在正式实验前固定，不根据测试准确率选择种子、位数或训练轮数。

## 数据和训练

使用仓库固定的 UCI bezdekIris 数据，150 个样本、4 个连续特征、3 个类别。数据归属和校验值见 [数据说明](../data/iris/README.md)。每类随机取 30/10/10 个样本，得到训练/验证/测试 90/30/30。均值和标准差只用训练集计算，标准差采用 ddof=0。每个模型保存全部行号、标准化参数和权重。

网络为 4 → 4 → ReLU → 3，其中第一层和输出层都带偏置。PyTorch CPU float64，全批量 Adam，学习率 0.01，最多 500 个 epoch，验证损失连续 50 轮没有超过 1e-8 的改善则停止，保存验证损失最好的权重；初始 epoch 0 也作为候选。种子预设为 20261109、20261110、20261111、20261112、20261113，同时指定各次的数据划分和权重初始化。测试集不进入训练函数，不参与标准化拟合、早停或超参数调整。

五次划分属于重复留出实验，样本可能跨运行重复；不将五组测试样本声称为 150 个独立的新样本。保存所有结果，不筛选表现最好的 seed。

## 光学部分做什么

训练结束后固定权重，将第一层 4×4 权重 W1 交给现有 SVD/Clements 编译器。每个模型只编译一次；光路逐器件执行，多个测试输入复用同一个器件配置。

输入标准化 → 复光场编码 → V† 网格 → 被动衰减 → U 网格 → 数字恢复比例 → 固定相位参考下取实部 → 数字偏置 → ReLU → 数字 4→3 分类头。

PyTorch 的权重存储为 W[out, in]，光路直接计算 W1 @ x；样本按行组成的数字批量参考为 X @ W1.T。两个表示不可误用转置。偏置、ReLU 和分类头明确保留为电子计算，不声称全光训练或全光网络。标准化后的负数以复数场幅度表示（负实数对应 π 相位），不是负光功率。

仿真假设可获取有共同参考的复数光场，并使用其实部。没有真实接收器标定、光电读出或每个输入的相位对齐；不能用 |E| 或 |E|² 替代该读出。保存残余虚部指标。数字恢复比例不能解释为光学增益，原始光路仍检查被动性。

## 对照和采样

数字网络和理想光路使用完全相同的权重与测试数据。额外检查零误差的显式物理控制模型与理想实现相符。

每个模型、每组非理想条件默认使用 30 个固定器件 seed，每台器件先创建一次，随后处理全部 30 个测试样本，不在样本之间重新抽取误差。同一模型不同条件复用 device seed，便于配对。

| 条件 | 设置 |
|---|---|
| 相位偏差 | 标准差 0.01、0.03、0.10 rad |
| 相位量化 | 4、6、8 bit |
| 插入损耗 | 每个 MZI 0.1 dB |
| 耦合器偏差 | 直通功率比 0.49 |
| 组合误差 | 0.01 rad、0.1 dB/MZI、8 bit、直通功率比 0.49 |

共 9 个非理想条件、5 个模型、每模型每条件 30 个器件，共 1,350 个条件内器件配置、40,500 次非理想测试预测。纯量化、损耗、耦合器条件不含随机相位偏差，因此同一模型的 30 个 seed 得到相同输出；保留配对结构，但不视为 30 个独立制造样本。

## 指标和验收

- 分类准确率、交叉熵、真实类别为行的混淆矩阵、逐样本预测。
- 与同模型数字结果的准确率差，单位为百分点；允许出现正值，不预设噪声必然降低每台器件的准确率。
- 第一层完整复输出、ReLU 后激活和最终 logits 的相对误差；使用整个测试集数组的范数比。额外记录第一层虚部范数/数字线性输出范数，不以强度代替场。
- 与数字模型预测的一致率；它不同于相对真实标签的准确率。
- 全部条件原始光路的被动性；理想和零误差模型的数值一致性，容差 1e-10。

PASS 表示软件一致性及被动性检查通过，不表示有误差光路达到指定准确率，更不表示真实硬件验证通过。纯数字模型的分类错误也照实保留。

每个 seed 的测试集只有 30 个样本，一次错分对应约 3.33 个百分点。汇总均值、中位数和经验 5%–95% 分位数；后者不是置信区间。跨模型与器件的混合分布只描述本实验。固定 CPU、版本和随机种子提高可复现性，但不保证不同平台的 PyTorch 训练权重逐位相同。

## 运行和结果文件

快速演示只需要原有 NumPy 环境：`python demo_week05.py`，从保存的首个模型读取权重，无需重新训练或联网。完整重跑先安装 `python -m pip install -r requirements-ai.txt`，然后运行 `python verify_week05.py`。

快速开发检查使用独立目录，例如 `python verify_week05.py --seeds 7 --trials 2 --max-epochs 10 --patience 5 --output-dir scratch_week05`，不能把此输出替代正式结果。运行 `python -m pytest -q` 检查回归；训练相关测试在未安装 PyTorch 时会显式跳过。

正式结果位于 progress/05_ai_extension：results.json 为方案、分组汇总和验收；devices.csv 为每台条件内器件的指标和完整预测；models/*.json 为权重、划分、训练曲线和光路参数；example.json 为预设首个模型/首台组合误差器件的完整复输出；图表均来自同批数据。重跑不会自动修改人工撰写的 README 结论。

## 后续边界

这是 Python 传输矩阵层面的混合光电推理验证。当前不包含校准、噪声感知训练、真实器件测量、Lumerical、速度/能耗优势或通用张量接口。后续创新实验可以复用保存的划分和模型做配对比较；若用这些测试结果反复选择新方法，需另设外部评估或嵌套划分，不能继续把同一测试集作为未见数据。

参考：[UCI Iris](https://archive.ics.uci.edu/dataset/53/iris)、[PyTorch Linear 的权重约定](https://docs.pytorch.org/docs/2.9/generated/torch.nn.Linear.html)、[PyTorch 可复现性说明](https://docs.pytorch.org/docs/2.9/notes/randomness.html)。
